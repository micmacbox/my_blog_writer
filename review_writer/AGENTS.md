# 네이버 블로그 작업

네이버 초안 작성·사진 첨부·임시저장 요청에서는 먼저 `NAVER_POSTING_SCRIPT.md`와 `NAVER_BROWSER_WORKFLOW.md`를 읽고 따른다. 자료 사전 점검은 `scripts/prepare_naver_post.py`로 수행한다.

사용자가 지정한 원고·사진을 fizz_report 블로그에 입력·업로드하고 임시저장하는 요청은 그 범위의 작업을 허용한 것이다. 같은 작업에 허락을 반복 요청하지 않는다. 실제 권한 확대나 보안 설정 변경은 이 요청에 포함되지 않는다. 권한은 자동으로 부여하거나 우회하지 않는다.

현재 Chrome을 지정하면 그 브라우저에서 진행하고, 탭/프레임/사진 경로는 매번 새로 확인한다. 발행은 별도 명시적 요청이 있어야 한다. 미완료 항목을 숨기거나 전체 완료로 보고하지 않는다.
